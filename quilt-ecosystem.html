01 The flagship: Quilt

A spreadsheet where every cell is a live, addressable capability. The grid is the runtime. The cell is the universal IO primitive. A cell can be a value, a formula, an HTTP call, a sensor, a program, an LLM, or any combination — and they all wire together with reactive propagation.

★ Flagship product

Quilt — the cell model

Cells reference each other by stable address (not by coordinate). Change one cell, every dependent rewires automatically. No callbacks, no event loops, no state machines — just cells. The same sheet format (YAML) runs everywhere.

value
A static value, a number, a string, an object.
formula
A computed expression over other cells. =price * quantity
api
An outbound HTTP call. Every request is a value.
sensor
A pull-based data source: prices, weather, IoT readings.
program
A function body. Full TypeScript closure in a cell.
router
Picks a value based on the caller. Per-context memoization.
listener
A push side-effect: notify, alert, fire webhook.
io
Bidirectional IO: WebSocket, MQTT, serial, anything.
ai
An LLM cell. z.ai, Kimi, DeepSeek, Cloudflare AI.

05 Set up your own system

Different goals need different setups. Pick yours:

💻

Just want to try it

Open the Quilt Live HTML file. No install. Works offline. Save as a cookie or downloadable file.

🌐

Build a web app

npm install @quilt/core @quilt/sdk. Import the engine. Add cells to your app. MCP-server compatible for free.

🤖

Add LLM cells

npm install @quilt/ai. 4 providers, content-addressed caching, cost tracking. Add kind: 'ai' cells to your sheet.

🦀

Need a binary

cargo install quilt-rust. Single static binary, no Node.js. axum, crossterm, embedded targets.

📡

Embedded / IoT

Quilt on an ESP32. cargo build --target xtensa-esp32-espidf. Sensors and motors as cells. WiFi sync to a Quilt on a Codespace.

☁️

Cloudflare Worker

wrangler deploy in the quilt-cloudflare repo. D1, KV, R2, Vectorize, Workers AI. 7 AI cell kinds.

🏗

Federated 3-tier system

ESP32 (sensors) + Jetson (vision) + Codespace (ML). The same sheet format, three hardware tiers. See the federation.

🧬

Self-improving agents

npm install @quilt/evolve. RLAIF as a first-class pattern. 4 components, 5 scopes, plateau detection. Run evolution loops against any sheet.

How synergy works: Quilt doesn't replicate the work of these repos. Instead, Quilt sheets can call into them via the standard cell transports (HTTP, MQTT, WebSocket). The same way a Quilt cell calls an external API, it can call a Claw, a cellular automaton, or a Cocapn vessel. The cross-pollination is at the protocol level, not the code level. This keeps every repo lean.
