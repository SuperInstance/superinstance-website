2. Conservation Checker ?A sequence conserves if splitting it into any two groups preserves C. Formally: C(A ∪ B) = C(A) + C(B) − overlap. For trit sequences, C = count(+1) + count(−1) is always additive.

4. Wavelet Decomposer ?Ternary Haar wavelet: at each level, pair adjacent values → coarse (average direction) and detail (difference). Conservation is preserved: C at level N equals C at level 0.
