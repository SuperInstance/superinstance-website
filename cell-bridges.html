What is this?

The SuperInstance org has 300+ GitHub repos. Many of them were built long before Quilt existed — but they were already expressing the cell model in different forms. A vessel-agent-system's digital twin is a graph of cells. A chart-room's four panels are four views of the same cells. A slackwater-tminus's coordination primitives are temporal cells.

This page is the discovery surface. Pick a system below, click Generate Quilt sheet, and watch it become a Quilt cell graph. Then load it in the 3-View Studio to see the same data as a top view, a front view, and a side view.
