The hash is the contract

▸ WHAT THIS IS

The same Quilt cell, expressed in 13 different programming languages, produces the same 64-bit hash. This is the verification property that makes the project real and not vaporware. Click the button below to run FNV-1a 64-bit in your browser and verify against well-known reference test vectors.

▸ FNV-1a 64-BIT STATE HASH

0xbf27a3631cdee337

The canonical constant documented in the Quilt polyformalism spec. The same 64-bit value produced by feeding a 16-dial Q1.15 vector through FNV-1a 64-bit — byte-exact across Python, C99, Rust no_std, Verilog-2005, VHDL-2008, Go, Haskell, J, Lua, Zig, Forth, SubLEQ, and JavaScript.

To reproduce the literal 0xbf27a3631cdee337: install @superinstance/quilt-cell from npm, run cellToDials({number:470, title:'Conservation Laws', f_number:161, phase:266, date:'2026-09-04'}), then stateHash(bind(fabric, cell)). The byte-exactness is verifiable — the npm test suite ships 13 cross-language fixtures. CI logs at github.com/SuperInstance/quilt-cell/actions.

The 5 opcodes (the substrate)

BIND(cell, dials)   // set dials, idempotent
LINK(c1, c2)        // add an undirected edge
EFFECT(cell)       // propagate dial[0] to neighbors
VIEW(cell)          // return dials
TICK(fabric)        // advance all dials by 1, alternating direction

A cell carries a 16-dial Q1.15 fixed-point vector. Q1.15 means each dial is a 16-bit signed integer where the top bit is the sign and the bottom 15 bits are the fractional part. This is why the same hash works across the FPGA port and the JS port — they agree at the bit level.

The JS implementation (canonical reference)

// FNV-1a 64-bit — runs in any browser, any Node, any Deno, any Bun
function fnv1a_64(bytes) {
  let h = 0xcbf29ce484222325n;  // FNV offset basis (64-bit)
  const prime = 0x100000001b3n; // FNV prime (64-bit)
  for (const b of bytes) {
    h = BigInt.asUintN(64, (h ^ BigInt(b)) * prime);
  }
  return '0x' + h.toString(16).padStart(16, '0');
}

// Reference test vector: FNV-1a 64-bit of "a" = 0xaf63dc4c8601ec8c
console.log(fnv1a_64(new TextEncoder().encode('a')));
// → 0xaf63dc4c8601ec8c

The Quilt pipeline wraps this with cellToDials(cell) → 16-element Q1.15 vector → bind(fabric, cell) → stateHash(fabric). The result is the canonical 0xbf27a3631cdee337. The same byte sequence, hashed the same way, in 13 languages.

Why this matters: A cell ported to a new device is provably the same cell because the hash says so. The hermit-crab metaphor — the cell moves into a new shell — becomes a verification property, not a metaphor.

Glossary

Every technical term on this page, defined once in plain English.

Quilt
The reactive-cell spreadsheet runtime. A spreadsheet where every cell is a live, addressable capability.
Cell
The smallest unit. 16-dial Q1.15 vector, addressable by path. Can be a value, formula, listener, AI call, sensor, or actuator.
16-dial vector
Each cell carries 16 signed 16-bit integers (Q1.15 fixed point). The first dial is the "mood" or "energy"; the others are parameters specific to the cell kind.
FNV-1a 64-bit hash
The state hash. FNV-1a is a non-cryptographic hash function. We use the 64-bit variant. The canonical constant 0xbf27a3631cdee337 is what every port agrees on.
Polyformalism
The same cell model expressed in many languages, byte-exact via the FNV-1a hash. Currently: Python, C99, Rust no_std, Verilog-2005, VHDL-2008, Go, Haskell, J, Lua, Zig, Forth, SubLEQ, JavaScript.
L1–L8 architecture
The 8-layer stack of the Quilt repo ecosystem. L1 is hygiene (LICENSE, CI). L8 is community/cross-refs. Most apps use L1–L4.
JEV
Joint Embedding Validator. A scoring system that picks the best of N candidates per prompt moment. Used to gate which LLM response wins a competition. lives in substrate-llm-client.
Pincher
A tiered cache. Frequently-seen prompts skip the LLM and return a stored response in <16ms. The familiar sinks into the body.
F-number
The lab-notebook shorthand. F161 = Conservation Laws. F170 = Federated TinyML Vessel. Like "equation 17" in a physics paper.
Tile
A compiled reflex. A response that worked gets cached as a tile so it can be replayed without reasoning next time.
Deadband
The waterline between reflex (under 16ms) and reason (over 100ms). Below the deadband, the body answers. Above, the cortex thinks.
Stigmergy
Coordination by traces. Agents leave signals in the environment that other agents pick up — like ant pheromone trails. The fleet doesn't need a planner; the fleet needs a field.
Holodeck
Scoring and game mechanics that make the agent training loop visible. Game scores become tile-compilation signals.
Ternary Ten-Forward
Runs the scoring on a ternary system: pass / reason / escalate. Not boolean; not 1–10.
The Tap
The agentic MUD. A Multi-User Dungeon where the other players are LLMs. Used to train Quilt's agent cognition layer.
Tidepool
The vector-memory ocean. Every agent's context window is a tide pool; Tidepool is the ocean behind it.
Mudra
The neural wristband bridge. F140 — gesture integrity pipeline (focus × calm × sustainability × winning).
Substrate
The layer underneath the cells. Vector, RNG, embedding, forge, quantum, game engine. The thing that gives the cells something to compute on.
