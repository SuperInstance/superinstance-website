How this works: Each tile is a value cell with name, tier, cpu, memory, connections, latency. The heatmap is a 2D projection of a 4D tensor (instances × {cpu, memory, connections, latency}). Click a metric to project that axis. Sort to reorganize. The Mermaid block is a text-to-diagram projection — paste it into any Mermaid renderer. The Markdown block is a human-and-agent-readable state file. The whole thing is a Quilt sheet running in your browser. Save your snapshot, share the JSON, render in TUI or PNG.
