How this works: Every message is a Quilt value cell with {id, parent_id, role, content, ts}. The chain forms a tree because every cell (except the root) has exactly one parent_id. A "branch" is the path from the root to any leaf — the path that's currently selected. The "context" for the next message is a window cell that slices the last N messages from the active path. Forks create new leaves; clicking a leaf in the sidebar switches the active path. The assistant cell is currently a placeholder — wire in an ai cell to get real responses. Learn about Quilt.
