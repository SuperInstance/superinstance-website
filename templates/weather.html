Each city is an api cell. Cells auto-refresh. Favorites save to localStorage.
← back to Quilt
How this works: Each city is a row in the grid, backed by an api cell that calls the Open-Meteo geocoding + forecast API. Auto-refresh on an interval is a listener cell. Saving favorites to localStorage is a value cell. The whole dashboard is a Quilt sheet running in your browser. Learn about Quilt.
