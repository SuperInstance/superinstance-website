Inspector

How this works: Each note is a Quilt value cell ({id, title, body, color, tags, x, y}). Each connection is a formula cell that references two notes ({from, to, label}). The SVG canvas is the rendered sheet: positions are persisted, and a tiny inline force-iteration settles the layout when you press Auto-layout. The right-hand panel edits the cell you clicked. Deleting a note is a cascade formula — it removes the note and every formula that references it. Search is a filter cell over title + tags. Learn about Quilt. 
   note ────── connection ────── note
   (value)    (formula)          (value)
     │            │                  │
   {id,        {from,            {id,
    title,       to,               title,
    body,        label}            body,
    color,                         color,
    tags,                          tags,
    x, y}                          x, y}

   cascade on delete: any formula whose from/to == deleted.id is also removed.
