The conservation rule

γ + η = C

Every operation tracks two quantities: γ (structure, order, signal) and η (noise, entropy, disorder). Their sum is constant. This is enforced in code at six points — definition, runtime, build-time lint, compile-time injection, GPU kernel boundaries, and CDN edge.

Honest note: γ + η = C is an accounting identity, not a physical law. We define η := C − γ. The engineering discipline is real — six crates verify it at different system layers. The mathematical theorem is not.
