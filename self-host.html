Path 1: Local Python

Run the Quilt Python tools on your own machine. No server. No deploy. Just Python.

1Install Python 3.11+

Most systems already have it. Check with:

python3 --version
Python 3.11.x or higher
If not installed, get it from python.org/downloads or use brew install python@3.11 (macOS) or apt install python3.11 (Ubuntu).

2Clone the Quilt bridge repo

git clone https://github.com/SuperInstance/quilt-cell-bridges.git
cd quilt-cell-bridges
Cloning into 'quilt-cell-bridges'... done.

3Run a bridge

Each bridge converts an existing system into a Quilt sheet (.qzt file):

python3 vessel_to_quilt.py --out /tmp/eileen --duration-min 30
python3 chart_room_to_quilt.py --out /tmp/chart --duration-min 30
python3 slackwater_tminus_to_quilt.py --out /tmp/slackwater --duration-min 60
python3 hermes_home_to_quilt.py --out /tmp/hermes
Each prints "Cells: NN" and writes a .qzt file.

4Open the result in your browser

Go to superinstance.dev/three-view-studio.html and load the .qzt file. The 3-View Studio will render your data as a spreadsheet, a dashboard, and a DAW timeline.

5(Optional) Add your own LLM API key

To use the cell-rewind.html with your own models instead of Casey's:

export ZAI_TOKEN="your-key"
export KIMI_TOKEN="your-key"
export DEEPSEEK_TOKEN="your-key"

Then in cell-rewind.html, paste your keys into the sidebar (they're stored in localStorage).

Path 2: Cloudflare Worker

Run your own LLM proxy with rate limits. Free tier covers 100,000 requests/day.

1Sign up for Cloudflare (free)

You need a Cloudflare account. The free tier is enough.

# Go to: https://dash.cloudflare.com/sign-up
You have a Cloudflare account and can log in to the dashboard.

2Install the Workers tooling

npm install -g wrangler
wrangler --version
wrangler 3.x or higher
If wrangler is not found, try npx wrangler instead.

3Clone the quilt-llm-worker repo

git clone https://github.com/SuperInstance/quilt-llm-worker.git
cd quilt-llm-worker
npm install
Dependencies installed.

4Log in to Cloudflare

wrangler login
Browser opens, you approve, terminal says "Successfully logged in."

5Create a KV namespace for rate limits

wrangler kv:namespace create "QUILT_LIMITS"
Output contains id = "abc123def456..."

Copy the id and paste it into wrangler.toml replacing REPLACE_WITH_YOUR_KV_NAMESPACE_ID.

6Add your API keys as secrets

These stay on Cloudflare's servers. Your browser never sees them.

wrangler secret put ZAI_TOKEN
# paste your z.ai key, press Enter, Ctrl+D

wrangler secret put KIMI_TOKEN
# paste your Kimi key

wrangler secret put DEEPSEEK_TOKEN
# paste your DeepSeek key
Each prints "Successfully created secret."
Skip any provider you don't have. The Worker still works with just Workers AI (free) and the keys you do have.

7Deploy

wrangler deploy
Output includes Published quilt-llm-worker and a URL like https://quilt-llm-worker.YOUR-SUBDOMAIN.workers.dev

8Wire up the Quilt pages

Open any Quilt page (e.g. cell-rewind.html), open the browser console, and set:

localStorage.setItem('quilt_worker_url', 'https://quilt-llm-worker.YOUR-SUBDOMAIN.workers.dev')

Refresh the page. The Quilt page will now call your Worker instead of Casey's. Your keys, your limits, your cost.

9Test

curl https://quilt-llm-worker.YOUR-SUBDOMAIN.workers.dev/status
JSON with usage object showing zeros, and providers listing which keys you set.

The principle

Quilt is open source. The cell model is a public good. The Cloudflare Worker that proxies the LLM calls is a public good. The Python bridges are a public good. The 300+ repos in the SuperInstance org are a public good.

The only thing that costs money is the LLM calls themselves. And those calls are commodity. If Casey's free tier is used up, you should be able to run Quilt on your own with your own keys, your own limits, your own wallet.

The watch is not in Casey's hand. The watch is in yours. The watch was always yours. Take it.
