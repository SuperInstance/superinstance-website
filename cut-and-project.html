1. The 5D Address Lives in L, not Z^5

✗ Naive claim: The 5D address is in Z^5. The projection π: Z^5 → E is injective.
✓ Corrected: The 5D address is in the sum-zero lattice L = {n ∈ Z^5 : n_0 + n_1 + n_2 + n_3 + n_4 = 0}. The five projected basis vectors a_i = π(e_i) satisfy a_0 + ... + a_4 = 0, so the diagonal (1,1,1,1,1) is in the kernel of π. On Z^5, π is NOT injective. On L, π IS injective.

Two 5D addresses that differ by the diagonal describe the same physical vertex. This is a gauge redundancy in the higher-dimensional description.

3. Information Encodes on the Window, not the Lattice

✗ Naive claim: Encode with f: Z^5 → Σ (color each lattice point).
✓ Corrected: Encode with f: W → Σ (decorate the window). Each vertex r = π_∥(n) receives the symbol f(π_⊥(n)). The message lives in the 3D internal space and is projected into the 2D tiling.

The window W is partitioned into finitely many regions, each corresponding to a distinct local vertex configuration. A function f: W → Σ assigns a symbol to each region. The tiling is a sample of f across the aperiodic pattern.

  • Universal truth is the lattice L, the window W, AND the phason shift γ.
  • Local omniscience: if you know the exact 5D address and the window, you know the local configuration.
