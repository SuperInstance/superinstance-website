Pick a tool. Or follow a workflow.

Every tool below is a self-contained page that does real work in your browser. They share state through localStorage — start a reflex database in Pincher, ship it as a .nail bundle, load it on an ESP32. Compose them however you need.

🔁 Common workflows — click to follow

Build a reflex engine from scratch

  1. Open Playground to learn how cells work
  2. Try Puzzle to get the hang of composing cells
  3. Open Pincher and pinch DevOps tasks — it learns reflexes
  4. Open .nail builder and click "Load from Pincher demo"
  5. Download the .nail bundle, ship it to a Worker / workstation / ESP32

Build a Quilt sheet from real data

  1. Open JSON → sheet and paste your JSON
  2. Copy the generated sheet, paste it into Playground
  3. Add derived cells, run it, see the values
  4. Export the sheet as a .nail bundle from .nail builder

Plan a deployment of quilt-elf

  1. Open Vibe to see the dashboard for invisible elves
  2. Open Token calculator and add your workload
  3. See if you fit within free tiers or need a metered provider
  4. Open Cron builder and pick a 15-min trigger (the default)
  5. Deploy @quilt/elf to Cloudflare Workers with the cron + tokens

Learn Quilt from React

  1. Open From React to Quilt for the mental model bridge
  2. Open Playground and load the "counter" example
  3. Open Inspector to see a dependency graph
  4. Open Puzzle and solve puzzles to build intuition
