🎯 The Thesis

The elephant repo (SuperInstance/elephant, Python, 28KB, 21 modules) is the room-temperature sense — a system that reads the vibe of any communication space. The repo IS the Room substrate made real.

Of Quilt's six substrates, Room has always been the most abstract: you are here with others — an address space with no weather. The elephant gives it weather. Every room acquires warmth, κ (concentration), gravity, reverberation, ripple. The room becomes something you can feel before you can name.

🌊 The Watch Oscillation Made Concrete

The watch has always oscillated: universal ↔ particular. The elephant makes this concrete with two presets:

🐘 Room-Elephant (universal)

The zeitgeist — objective, first-class, not any agent's view. Two agents reading the same room get the same field. The room's own identity. Does not drift with any one agent.

Used for: MUD description, NPC vibes, input-tokens every agent sees

👤 Personal-Elephant (particular)

Subjective feel — dial_weights (which dials matter to you), bias (disposition), attachments (intangible correlations: the perfume = grandma's shop).

Used for: that agent's reactions, decisions, memories

┌─────────────────────────────────────────────────┐ │ THE WATCH OSCILLATES │ │ │ │ Room-Elephant ←─acclimation─→ Personal │ │ (universal) (agent→room) (particular) │ │ ↑ │ │ │ └─────charisma────── │ │ │ (room→agent) │ │ │ ↓ │ │ New Personal │ │ re-tunes dials │ └─────────────────────────────────────────────────┘

Acclimation (agent → room): a newcomer warms to the room's vibe. Charisma (room → agent): a strong presence pulls the room's field toward itself. The watch doesn't just oscillate in Quilt. It oscillates because rooms have inhabitants with attachments.
