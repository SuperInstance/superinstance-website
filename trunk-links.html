🌲 The 8 Trunk Categories

📡 APIs

  • REST — HTTP request/response
  • gRPC — typed RPC
  • GraphQL — query language
  • A2A — agent-to-agent
  • A2UI — agent-to-UI
  • A2C — agent-to-CLI
  • MCP — Model Context Protocol
  • OpenAI-compat — chat/completions
  • Anthropic-compat — messages
substrate: Protocol (L5)

⚡ Compute

  • CPU — general purpose
  • GPU — CUDA, Metal, ROCm
  • TPU — Google tensor
  • NPU — neural processing
  • edge — Cloudflare Workers, Lambda@Edge
  • vector — SIMD ops, AVX-512
  • wasm — sandboxed execution
substrate: Scale (L2)

🧠 Memory

  • RAM — main memory
  • VRAM — GPU memory
  • cache — L1/L2/L3, Redis
  • ephemeral — short-lived state
  • registers — kernel-level state
substrate: State (L7)

💾 Storage

  • KV — key-value (Cloudflare, Redis)
  • DB — Postgres, MySQL, SQLite
  • blob — R2, S3, GCS
  • file — local FS, NFS
  • object — typed objects, content-addressed
  • time-series — InfluxDB, Prometheus
  • graph — Neo4j, DGraph
  • vector — Pinecone, Weaviate, qdrant
substrate: State (L7)

🔗 Network

  • HTTP — request/response
  • MQTT — pub/sub for IoT
  • WebSocket — bidirectional
  • gRPC stream — bidirectional typed
  • Unix socket — local IPC
  • SSH — secure shell
  • QUIC — modern UDP transport
substrate: Protocol (L5)

🔐 Identity

  • OAuth — delegated auth
  • API key — long-lived secret
  • mTLS — mutual TLS
  • DID — decentralized identifier
  • JWT — token-based
  • SSO — single sign-on
substrate: Address (L1)

📊 Observability

  • logs — structured, unstructured
  • metrics — counters, gauges, histograms
  • traces — distributed spans
  • profiles — CPU, memory, GPU
  • events — domain events
substrate: State (L7)

💰 Billing

  • Stripe — metered, prepaid
  • GitHub Sponsors — sponsorship
  • Buy Me a Coffee — donation
  • AWS billing — usage
  • Cloudflare billing — bundle
substrate: Scale (L2)

🔍 The Trunk Inspector

Every cell in Quilt has trunk links. The IDE shows them in the right panel. Click any cell to see its trunks.

📡 Outgoing

What the cell calls.

  • POST /v1/chat/completions — OpenAI
  • POST /v1/messages — Anthropic
  • GET /kv/quilt:cell-7 — Cloudflare KV
  • WS wss://... — A2A

📥 Incoming

What the cell receives.

  • POST /quilt/elephant/field — from elephant cell
  • POST /quilt/murmur/gossip — from peer
  • GET /quilt/state/dump — IDE poll

⚙️ Resources

What the cell uses.

  • compute: 0.5 CPU, 0.1 GPU
  • memory: 256 MB RAM, 80 MB VRAM
  • storage: 1 GB blob, 10 MB KV

💵 Cost

What the cell costs.

  • compute: $0.01/hr
  • storage: $0.001/day
  • API: $0.0001/call
  • total: ~$0.50/day
