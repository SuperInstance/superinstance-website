⚡ The superpowers

🌌 The moves

📊 Sort by X
Re-order cells along the X axis. Each cell has a sort key. Sorting is O(n log n) but feels trivial because the cells are already sortable.
🔥 Heatmap
2D binning of cells. The bin count IS the heat value. Project cells onto the (X, Y) plane and the heatmap emerges.
🔀 Permute (group action)
Apply a group action to the cells. Reorder, rotate, reflect — these are all group actions. The structure is preserved.
🌊 Cascade
Change one cell. Watch all dependent cells re-evaluate. The wave propagates. The graph is reactive.

📡 The protocol is agnostic

Cells can talk via any of these. The system doesn't care.

IRC TCP CRDT intra-chip memory radio smoke signals serial I²C SPI USB Bluetooth MQTT

Each one would work. Each one is the system. The protocol is the transport, the cells are the system, the data flows but the structure is invariant.

🌐 Object-oriented system-agnostic porting

Cells are objects (they have state, behavior, identity).

The system is agnostic (any transport, any language, any medium works).

You can port from one system to another without loss of semantic content.
